TRAZOS - se escriben, uno detras del otro:

    escribir_1    trimPathEnd    0 -> 1      260         0        260
    escribir_2    trimPathEnd    0 -> 1      260        70        330
    escribir_3    trimPathEnd    0 -> 1      260       140        400

    escribir_5    trimPathEnd    0 -> 1      260       280        540

    paso   de -> a    duracion   retardo   termina   que se lee
      1    0 -> 1        80        560       640     se enciende
      2    1 -> 0        70        640       710     se apaga
      3    0 -> 0        60        710       770     oscuro (intervalo del tally)
      4    0 -> 1        70        770       840     segundo flash
      5    1 -> 0        70        840       910     se apaga
      6    0 -> 1        70        910       980     se enciende y se queda

ORDEN INNEGOCIABLE: el ultimo trazo termina en 540 -> el punto no existe hasta
560 -> dos apagones completos -> ultimo estado 1.

    Interpolador de los trazos: @android:interpolator/decelerate_quad
    Interpolador del punto: lineal. Un tally no tiene resorte.

    El fillAlpha del punto SI va a 0. Las camaras se apagan del todo. Eso no es el
    error del 30% en los renglones.

    No uses valle 0.55. Se lee LED enfermo, no REC.
    No agregues un tercer flash. En 1000 ms, tres veces parece aviso de bateria.

Cada animador de trazo es su archivo en android/app/src/main/res/animator/
(escribir_1.xml ... escribir_5.xml): objectAnimator, propertyName="trimPathEnd",
valueType="floatType".

punto_late.xml es un <set> de los seis pasos de arriba sobre fillAlpha. El paso 3
